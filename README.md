# FrameShelf 블로그 연동 목업

영상·대본·글쓰기 작업 공간의 독립 시안입니다. 예시 데이터만 포함합니다.

- 새 글과 기존 글 선택
- 작성 중 초안과 게시글 목록
- 제목 검색과 태그 필터
- 태그 추가·삭제와 글 단위 브라우저 초안
- 모바일 목록 시트와 패널 탐색

게시는 시연이며 실제 블로그 API를 호출하지 않습니다.
실제 강의 영상·대본·블로그 글과 인증 정보는 포함하지 않습니다.

`index.html`은 상태별 검토 화면입니다. `workspace.html`은 전체 미리보기입니다.
로컬 확인: `python3 -m http.server 5201`
상태 검사: `node model.check.mjs`
